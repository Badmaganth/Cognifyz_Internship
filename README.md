
# Cognifyz Full Stack Development Internship

This repository contains my work and projects from my Full Stack Development Internship at Cognifyz Technologies.

During this internship, I gained practical experience in full-stack web development and learned how frontend and backend components work together to build web applications.

## Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- JavaScript
- REST APIs

## About the Internship

The internship helped me improve my understanding of full-stack development and apply my technical knowledge while working on web applications.

I explored frontend development, backend API integration, and database connectivity using the MERN stack.

## What I Learned

- Building user interfaces using React.js
- Developing backend services using Node.js and Express.js
- Creating and integrating REST APIs
- Connecting web applications to MongoDB
- Understanding the flow of data between frontend and backend
- Organizing code for full-stack applications
