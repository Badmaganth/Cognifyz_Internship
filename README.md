
# Cognifyz Internship Tasks

This repository contains the tasks I completed during my Full Stack Development Internship at Cognifyz Technologies.

I worked on these tasks to practise frontend development, JavaScript, form validation, and REST API integration.

## Tasks Completed

### Task 3: Responsive Dashboard

- Created a responsive dashboard layout using HTML, CSS, and Bootstrap.
- Added dashboard cards for analytics, integration, and security.
- Used CSS transitions and hover effects to improve the interface.
- Added a fade-in animation to the dashboard heading.

**File:** `task3.html`

### Task 4: Form Validation and Dynamic DOM

- Created a simple page with Home and Register views.
- Added a password-strength indicator.
- Checked password length, uppercase letters, numbers, and special characters.
- Added password length validation before form submission.
- Used JavaScript to update the page dynamically.

**File:** `task4.html`

### Task 5: REST API Interaction

- Created a REST API using Node.js and Express.js.
- Implemented a GET endpoint to retrieve items.
- Implemented a POST endpoint to add new items.
- Implemented a DELETE endpoint to remove items.
- Connected the API to a simple HTML page using JavaScript Fetch API.

**Files:** `server.js` and `task5.html`

## Technologies Used

- HTML5
- CSS3
- Bootstrap
- JavaScript
- Node.js
- Express.js
- REST APIs

## What I Learned

Through these tasks, I gained practical experience in creating responsive web pages, using JavaScript for form validation and DOM manipulation, and connecting a frontend page to backend API endpoints.

## How to Run Task 3 and Task 4

Open `task3.html` or `task4.html` in a web browser.

## How to Run Task 5

1. Install Node.js and npm.
2. Clone this repository:

   ```bash
   git clone https://github.com/Badmaganth/Cognifyz_Internship.git
   cd Cognifyz_Internship
   ```

3. Install the project dependencies:

   ```bash
   npm install
   ```

4. Start the API server:

   ```bash
   node server.js
   ```

5. Open `task5.html` in a browser and use the page to add and delete items.

The API runs locally at `http://localhost:3000`.
