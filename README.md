# Cognifyz Technologies – Full Stack Development Internship

This repository contains the work completed as part of my Full Stack Development Internship at Cognifyz Technologies. It includes five tasks focused on HTML forms, server-side development, responsive web design, form validation, DOM manipulation, and REST API integration.

## Tasks Completed

### Task 1: HTML Structure and Basic Server Interaction
- Created HTML forms to collect user input.
- Used Node.js and Express.js for server-side processing.
- Practiced handling form submissions.
- Explored dynamic HTML rendering using EJS templates.

### Task 2: Inline Styles, Basic Interaction, and Server-Side Validation
- Implemented interactive forms and input validation.
- Practiced client-side validation using JavaScript.
- Worked with server-side validation using Express.js.
- Used temporary in-memory storage for submitted registration data.

### Task 3: Advanced CSS Styling and Responsive Design
- Created a responsive dashboard interface.
- Used HTML, CSS, and Bootstrap for styling and layout.
- Practiced transitions, animations, and visual effects.
- Focused on creating user-friendly web interfaces.

### Task 4: Complex Form Validation and Dynamic DOM Manipulation
- Implemented password validation rules.
- Created a password strength indicator.
- Used JavaScript to manipulate the DOM dynamically.
- Updated webpage elements based on user input.

### Task 5: API Integration and Frontend Interaction
- Created REST API endpoints using Node.js and Express.js.
- Implemented GET, POST, and DELETE operations.
- Connected frontend components to the backend using the Fetch API.
- Practiced sending HTTP requests and displaying API data.
