# Cognifyz Technologies – Full Stack Development Internship

This repository contains my work from the Full Stack Development Internship at Cognifyz Technologies. I completed the first five tasks assigned in the internship program, covering HTML forms, server-side development, responsive design, form validation, DOM manipulation, and REST API integration.

## Tasks Completed

### Task 1: HTML Structure and Basic Server Interaction
- Created HTML forms to collect user input.
- Worked with a Node.js and Express server.
- Practiced handling form submissions and server-side processing.
- Explored dynamic HTML rendering.

### Task 2: Inline Styles, Basic Interaction, and Server-Side Validation
- Worked on form interactions and input validation.
- Practiced client-side validation using JavaScript.
- Explored server-side validation and temporary data storage.

### Task 3: Advanced CSS Styling and Responsive Design
- Designed a responsive dashboard interface.
- Used HTML, CSS, and Bootstrap.
- Added styling effects, transitions, and animations.

### Task 4: Complex Form Validation and Dynamic DOM Manipulation
- Implemented a password strength indicator.
- Added password validation rules.
- Used JavaScript to update page elements dynamically based on user input.

### Task 5: API Integration and Front-End Interaction
- Created REST API endpoints using Node.js and Express.
- Implemented GET, POST, and DELETE operations.
- Connected the frontend to the backend using the Fetch API.
- Practiced sending requests and displaying API data.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Node.js
- Express.js
- REST APIs
- Fetch API

## What I Learned

Through these tasks, I gained practical experience in frontend development, form validation, responsive design, server-side programming, and communication between a frontend and a backend API.

The repository contains the implementation files available for the completed tasks. Tasks 1 and 2 were worked on in existing files rather than maintained as separate task-specific files.
